## 1. 产品简介

仓库分析工作台是一款**本地优先**的库存品类分析决策工具。您把 Excel/CSV 形式的货品主数据与库存流水导入到本机，软件在本地完成清洗校验，并输出结构化分析指标——动销率、周转、库龄、ABC 分层、呆滞金额、补货建议、需求预测与行业基准对比——辅助您做采购与库存决策。

**您的数据保存在您自己的电脑上**：所有业务数据（货品、流水、成本、分析结果）存储在本机数据库中，不上传业务明细到云端。云端只负责账号登录、授权与状态同步，断网时本地核心工作不中断。

### 1.1 主要功能一览

| 功能 | 说明 | 见章节 |
|---|---|---|
| 数据导入 | 五步向导导入货品主数据（SKU）与库存事件 CSV | §5 |
| 运行分析 | 一键计算五类公式共 18 个指标，含告警提示 | §6 |
| 报告导出 | 将历史分析导出为 HTML / CSV 报告 | §7 |
| 备份恢复 | 一键全量备份数据库，校验后可恢复 | §8 |
| 在线登录 | 登录后显示许可证与设备状态；不登录可离线使用 | §3 |

## 2. 安装与卸载

### 2.1 系统要求

- Windows 10 / 11（64 位）
- 无需预装 Python 或其他依赖——安装包已内置全部运行环境
- 磁盘空间：安装约 400MB；使用中会随数据增长产生数据库与备份文件

### 2.2 安装步骤

1. 取得安装包 `WarehouseWorkbench-Setup-0.1.0.exe` 与校验文件 `SHA256SUMS.txt`；
2. （建议）核验安装包完整性：在 PowerShell 中执行
   `Get-FileHash .\WarehouseWorkbench-Setup-0.1.0.exe -Algorithm SHA256`，
   输出值与 `SHA256SUMS.txt` 中记录的哈希一致则包完好；
3. 双击安装包，按向导完成安装。默认安装位置 `C:\Program Files\WarehouseWorkbench`，安装向导为简体中文；
4. 安装完成后自动创建：
   - 桌面快捷方式「仓库分析工作台」
   - 开始菜单「仓库分析工作台」（含主程序与卸载入口）
   - 控制面板「应用」列表中出现「仓库分析工作台 0.1.0」

### 2.3 首次运行的 SmartScreen 提示（预期行为）

当前版本未做代码签名，首次运行时 Windows 可能弹出 SmartScreen 安全提示。这是未签名软件的**正常现象**：

> 点击「更多信息」→「仍要运行」即可正常进入程序。

### 2.4 数据保存位置（重要）

**所有用户数据都保存在 `%LOCALAPPDATA%\WarehouseWorkbench`**（即 `C:\Users\<您的用户名>\AppData\Local\WarehouseWorkbench`），包含：

| 内容 | 位置 |
|---|---|
| 业务数据库 | `%LOCALAPPDATA%\WarehouseWorkbench\data\warehouse.db` |
| 手动/自动备份 | `%LOCALAPPDATA%\WarehouseWorkbench\backups\` |
| 导出的报告 | `%LOCALAPPDATA%\WarehouseWorkbench\reports\` |
| 登录凭据 | `%LOCALAPPDATA%\WarehouseWorkbench\`（加密存储） |

安装目录（Program Files）内**不会**产生任何用户数据。

### 2.5 升级

关闭正在运行的工作台 → 直接运行新版本安装包覆盖安装即可。旧数据全部保留，升级后可直接继续使用。

### 2.6 卸载

控制面板 →「应用」→「仓库分析工作台」→ 卸载（或使用开始菜单中的卸载入口）。

**卸载不会删除您的业务数据**：数据库、备份与报告仍保留在 `%LOCALAPPDATA%\WarehouseWorkbench`。如需彻底清理，请在卸载后手动删除该目录。

## 4. 准备数据

工作台接受 **CSV 文件**两种导入：**货品主数据（SKU）** 与 **库存事件**。文件编码支持 UTF-8（推荐，含带 BOM 的 UTF-8）与 GBK，软件自动识别。

### 4.1 货品主数据（SKU）CSV 格式

表头与示例：

```csv
sku_id,name,category,sub_category,unit,unit_cost,industry
SKU-0001,矿泉水550ml,饮料,瓶装水,箱,45.00,食品饮料
```

| 列 | 必填 | 说明 |
|---|---|---|
| `sku_id` | 是 | 货品唯一编码，同一货品请保持一致 |
| `name` | 是 | 货品名称 |
| `category` | 是 | 一级品类（如：饮料） |
| `sub_category` | 否 | 二级品类（如：瓶装水） |
| `unit` | 是 | 计量单位（如：箱、瓶、个） |
| `unit_cost` | 否 | 单位成本（元）。缺失时该货品的价值类指标按降级口径计算并产生告警，不会中断导入 |
| `industry` | 否 | 所属行业（用于行业基准匹配） |

### 4.2 库存事件 CSV 格式

表头与示例：

```csv
event_id,sku_id,warehouse_id,move_type,quantity,occurred_at,unit_cost,source_ref
EVT-20260601-001,SKU-0001,WH-01,INBOUND,200,2026-06-01,45.00,PO-2026-001
```

| 列 | 必填 | 说明 |
|---|---|---|
| `event_id` | 是 | 事件唯一编号，**重复编号会被拒绝**（防重复导入） |
| `sku_id` | 是 | 货品编码，须已存在于主数据 |
| `warehouse_id` | 是 | 仓库编号（默认仓库为 `WH-01`） |
| `move_type` | 是 | 事件类型，见下表 |
| `quantity` | 是 | 数量（恒为正数，方向由事件类型决定） |
| `occurred_at` | 是 | 发生日期（如 `2026-06-01`） |
| `unit_cost` | 否 | 单位成本（元） |
| `source_ref` | 否 | 业务单据号（如采购单号），便于追溯 |

**8 种事件类型（`move_type`）**：

| 取值 | 含义 |
|---|---|
| `INBOUND` | 入库 |
| `OUTBOUND` | 出库 |
| `RETURN` | 退货入库 |
| `SCRAP` | 报损报废 |
| `ADJUSTMENT` | 库存调整 |
| `TRANSFER_OUT` | 调拨出 |
| `TRANSFER_IN` | 调拨入 |
| `REVERSAL` | 冲销（更正此前的事件） |

> **数据修正原则**：发现错误请通过 `REVERSAL`（冲销）或 `ADJUSTMENT`（调整）事件更正，不要试图直接修改已导入的历史数据。

### 4.3 建议的导入顺序

**先导入货品主数据，再导入库存事件**——库存事件中引用的 `sku_id` 必须已存在于主数据，否则该行会校验失败。若随交付附有示例数据（`mock-data/` 目录下两份 CSV：8 条 SKU 主数据与 23 条库存事件），可先用它练手熟悉流程。

## 5. 导入数据（五步向导）

进入「导入」页 → 点击「**打开导入向导...**」。向导共五步：

### 第 1 步 · 选择文件

点击选择要导入的 CSV 文件（编码自动探测：UTF-8 / GBK）。

### 第 2 步 · 导入类型与字段映射

1. 选择导入类型：**主数据（SKU）** 或 **库存事件**；
2. 把每个契约字段映射到您 CSV 的列名。若您的 CSV 列名与标准字段名一致，向导会自动匹配；
3. **必填字段不可留空**——缺失必填映射时「下一步」不可点击并给出提示。

### 第 3 步 · 预览

显示前 20 行原始数据供您核对列映射是否正确（本步不含校验结果）。

### 第 4 步 · 执行与结果

点击「**开始导入**」执行。导入完成后显示结果摘要（成功条数等）。

### 第 5 步 · 错误明细（如有）

若存在校验失败的行，向导最后会显示「错误明细」页，逐行列出失败原因（例如：`sku_id` 不存在于主数据、`event_id` 重复、数量非正数、日期格式不正确等）。**按修复建议修正 CSV 文件后重新导入即可**——已成功的行不会重复导入（事件按 `event_id` 去重）。

导入完成后，「导入」页会回显最近一次导入的结果。

## 6. 运行分析

进入「分析」页。

### 6.1 运行一次分析

点击「**运行分析**」。软件自动读取本地库全部数据，执行校验并计算五类公式共 **18 个指标**。运行结束后页面显示：

| 区域 | 内容 |
|---|---|
| **运行信息** | 本次运行的运行 ID（`run-` 开头）、引擎版本、公式版本、基准数据版本 |
| **指标明细** | 每个指标一行：指标 / 值 / 单位 / 公式 ID / 说明 |
| **告警** | 数据异常或降级提示：级别（阻断/警告/提示） / 代码 / 说明 / 涉及字段 |

### 6.2 看懂指标明细表

五类共 18 个指标（完整口径见软件附带的 `docs/formula-spec.md`，此处为通俗解释）：

| 类别 | 指标 | 通俗含义 |
|---|---|---|
| 基础 KPI | 期初库存量 | 分析期间开始时的库存数量 |
| 基础 KPI | 期末库存量 | 分析期间结束时的库存数量 |
| 基础 KPI | 出库量 | 期间累计出库数量 |
| 基础 KPI | 动销率 | 期间发生过出库的 SKU 占比，反映「货是不是在动」 |
| 基础 KPI | 库存价值 | 期末库存按成本计的金额 |
| 基础 KPI | 周转率 / 周转天数 | 库存周转快慢；天数越短资金占用越少 |
| 基础 KPI | 覆盖天数 | 当前库存还能支撑多少天出库 |
| 成本 | 销货成本（COGS） | 期间出货的成本（按移动加权平均计算） |
| ABC 与库龄 | ABC 分层 SKU 数 | 按出库金额把货品分为 A/B/C 层（A 类贡献约 80% 出库金额） |
| ABC 与库龄 | 平均库龄 | 库存货物的平均存放天数 |
| ABC 与库龄 | 呆滞金额 | 长期无动销（默认 90 天观察窗口）货品的库存金额 |
| 补货 | 安全库存 | 为应对需求波动应保有的最低库存量 |
| 补货 | 补货点 | 库存降到该值时应当补货 |
| 补货 | 建议补货量 | 系统建议的补货数量（参数缺失时不输出并提示） |
| 预测 | 下周需求预测 | 基于历史出库的 4 周移动平均预测 |
| 预测 | 预测误差（MAPE） | 预测模型的准确度（样本不足时自动降级并提示） |
| 基准 | 基准偏差比率 | 您的指标与行业基准的相对偏差；未配置基准数据时提示「无基准数据」 |

指标值显示 `—` 表示该指标因数据不足（如缺少成本）本次未产出，对应原因会在告警表说明。

### 6.3 看懂告警表

告警按**校验 → KPI → ABC/库龄 → 补货 → 预测 → 基准**的顺序列出，每条包含：

- **级别**：标注「（阻断）」的是导致分析无法完成的问题（通常是数据校验失败）；其余为提示性告警；
- **代码**：机器可读的告警编号（如 `BENCHMARK_UNAVAILABLE`）；
- **说明**：人话描述的问题与原因；
- **字段**：涉及的字段，便于定位到 CSV 修正。

**常见非阻断告警**：缺单位成本（价值类指标降级）、无基准数据（基准对比跳过）、预测样本不足（预测降级）。这些不影响其他指标的计算。

### 6.4 历史记录

页面下方「历史运行」表列出每次分析的：运行 ID / 期间 / 状态 / 引擎版本 / 公式版本 / 运行时间。选中一行点击「**查看结果**」（或双击行）可重新查看该次运行的完整指标与告警。

## 7. 导出报告

进入「报告」页。

1. 点击「**刷新列表**」获取历史分析运行；
2. 在列表中选中要导出的一次运行；
3. 点击「**导出 HTML**」或「**导出 CSV**」：
   - **HTML**：适合直接查看与转发，浏览器打开即为排版好的报告；
   - **CSV**：适合导入 Excel 做进一步加工；
4. 点击「**打开所在目录**」查看导出文件（默认在 `%LOCALAPPDATA%\WarehouseWorkbench\reports\`）。

对同一次运行重复导出会**重新生成并覆盖**同名文件，不会报错、也不会产生重复文件。

## 8. 备份与恢复

进入「备份」页。**强烈建议在每次重要数据导入后手动备份一次**。

### 8.1 手动备份

点击「**手动备份**」。软件对当前数据库做**全量快照**（VACUUM INTO 方式生成独立备份文件），自动计算校验值（SHA-256）并登记到备份记录，状态为「已验证」。

备份列表展示：备份编号 / 备份时间 / 类型（手动/自动）/ 大小 / 状态 / 验证时间。

### 8.2 自动备份

软件会按调度策略自动备份（类型显示为「自动」），与手动备份并列展示在同一列表。

### 8.3 恢复备份

1. 在列表中选中一个备份，点击「**恢复此备份...**」；
2. 弹出确认对话框，请确认所选备份的时间点；
3. 确认后软件先**校验备份完整性**（哈希）与**数据库版本兼容性**，通过后原子替换当前数据库——恢复过程中断电等异常不会损坏现有库；
4. 恢复完成后当前数据回到所选备份时点的状态。

> 注意：恢复会**覆盖**备份时点之后的全部数据变更（包括之后导入的数据与分析结果）。如有需要，恢复前可先手动做一次当前状态的备份。

## 9. 在线状态与后台同步

- 登录后，工作台通过托盘后台代理保持与服务端的连接：定期上报心跳、拉取配置与任务、同步本地事件状态；
- 总览页「待同步」数字表示尚未上行的本地事件数，恢复网络后自动继续；
- **全部同步内容为控制数据与脱敏技术日志，不包含您的库存业务明细**；
- 断网不影响本地任何操作，重新联网后自动恢复同步。

## 10. 常见问题（FAQ）

**Q1：双击安装包提示「Windows 已保护你的电脑」（SmartScreen）？**
未签名软件的预期行为。点击「更多信息」→「仍要运行」。分发方提供的 `SHA256SUMS.txt` 可用于核验安装包未被篡改。

**Q2：不登录能用吗？**
可以。取消登录进入离线模式，导入、分析、报告、备份全部可用；仅许可证/设备状态等在线展示不可用。

**Q3：导入时提示「sku_id 不存在」？**
库存事件引用了主数据中不存在的货品。请先完成货品主数据（SKU）导入，或修正事件 CSV 中的货品编码。

**Q4：导入时提示「event_id 重复」？**
该事件编号已导入过。若确属新事件，请修改为新的唯一编号；若想更正旧事件，请使用 `REVERSAL` 冲销事件。

**Q5：分析结果里某些指标是「—」？**
该指标所需输入不足（最常见是缺单位成本）。查看告警表中的对应说明；补齐数据后重新运行分析即可。

**Q6：提示「无基准数据」（BENCHMARK_UNAVAILABLE）？**
行业基准数据尚未配置。基准对比为可选能力，不影响其他 17 个指标；如需开启，请联系服务提供方配置基准数据。

**Q7：想搬移到新电脑？**
在新电脑安装工作台 → 在旧电脑做一次手动备份 → 把备份文件拷贝到新电脑 `%LOCALAPPDATA%\WarehouseWorkbench\backups\` → 在新电脑「备份」页恢复该备份。

**Q8：卸载会删掉我的数据吗？**
不会。卸载只移除程序，数据保留在 `%LOCALAPPDATA%\WarehouseWorkbench`；彻底清理需手动删除该目录。

**Q9：软件启动后状态栏显示「安全模式（只读）」？**
本地数据库迁移未完成，软件自动进入只读保护。请联系支持人员处理，不要反复强行重启。

**Q10：CSV 用 Excel 打开再保存后导入失败？**
Excel 另存时可能改变编码或把长编号（如 `EVT-...`）转为科学计数法。请用「CSV UTF-8」格式保存，并在保存前确认编号列仍为完整文本。
